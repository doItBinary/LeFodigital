# Frontend de LeFodigital

Aplicación Angular 22 organizada por funcionalidades standalone.

La guía completa de configuración, pruebas y despliegue está en el
[`README.md` raíz](../README.md).

Comandos principales:

```powershell
pnpm install --frozen-lockfile
pnpm start
pnpm test
pnpm run build
```

El código TypeScript, HTML y SCSS se conserva en archivos separados. La API se
consume mediante la ruta relativa `/api/v1`.
